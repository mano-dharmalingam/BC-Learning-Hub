# ApprovalWorkflow

## Description
Custom multi-level approval engine

## Key Technologies
Events, Approval Entry, Email

## Getting Started
1. Clone repo
2. Open in VS Code with AL extension
3. Update app.json with your publisher + ID range
4. Download symbols: Ctrl+Shift+P → AL: Download Symbols
5. Deploy: F5
