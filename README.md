Comprehensive Business Central learning, knowledge-sharing, onboarding, architecture, and demo project repository.

## 🎯 Who Is This For?
| Role | What You Get |
|------|-------------|
| New AL Developer | Basics, syntax, first extensions |
| Senior Developer | Patterns, advanced topics, integrations |
| Technical Lead | Architecture, DevOps, design patterns |
| Solution Architect | Integration patterns, multi-tenant design |

## 📚 Learning Roadmap
```
01-AL-Basics → 02-Tables → 03-Pages → 04-Codeunits
→ 07-Events → 08-APIs → 09-Integration → 10-Advanced
→ 11-AI → 12-DevOps → 15-DesignPatterns → DemoProjects
```

├── 07-Events/          Publishers, Subscribers, Integration, Business

├── 09-Integration/     REST, Azure Functions, Service Bus, Blob
├── 10-Advanced/        Interfaces, Enums, Background Sessions, Queries
├── 11-AI/              Azure OpenAI, Copilot, RAG, AI Chatbot
├── 12-DevOps/          Git, GitHub Actions, Azure DevOps, CI/CD
