# Contributing to BC-Learning-Hub

## How to Contribute
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-topic`
3. Follow the README template in each folder
4. Ensure AL code compiles (use AL Language extension in VS Code)
5. Submit a pull request with a clear description

## README Template
Every topic folder must have a README.md with:
- Objective
- Business Scenario  
- Concepts Covered
- AL Code Example
- Step-by-Step Explanation
- Screenshots Placeholder
- References

## AL Standards
- Object IDs 50000–59999 for examples
- DataClassification on all fields
- XML comments on public procedures
- No hardcoded user-visible strings — use labels
